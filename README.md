# Werkbank

Fenster- und Türaufmaß per Foto mit Referenzobjekt (DIN A4). Installierbare, offline-fähige
Progressive Web App – Vanilla HTML/CSS/JS, kein Build-Schritt, keine externen Abhängigkeiten.

Live: über GitHub Pages veröffentlicht (siehe Repository-Einstellungen für die aktuelle URL).

## Lokal starten

```bash
python3 -m http.server 8000
```

Dann im Browser öffnen: http://localhost:8000/ (Kamera/PWA-Funktionen brauchen einen
secure context – `localhost` zählt als sicher).
